    1
    Connect to the OLT via Telnet
    From a PC on the same network as the OLT
    Terminal
    telnet {{ olt.ip_address }}{% if olt.telnet_port != 23 %} {{ olt.telnet_port }}{% endif %}
    Log in with your current OLT admin credentials first — you will create the dedicated SmartOLT user in Step 2.
    2
    Create Dedicated SmartOLT User
    Separate account used only by SmartOLT — never share with human operators
    ZTE CLI
    conf t
username autoolt password autoolt123 max-sessions 16 privilege 15
    privilege 15 is required — SmartOLT needs full read access to poll ONU states and port statistics.
    3
    Enable Telnet (Disable SSH-only Mode)
    SmartOLT connects via Telnet — ensure it is not blocked
    ZTE CLI
    conf t
! Allow Telnet connections (disable SSH-only restriction)
no ssh server only
! Set telnet on line vty
line vty 0 15
 login local
 privilege level 15
! Save
end
write
    4
    Configure SNMP Communities
    Read and write community strings for monitoring and polling
    ZTE CLI
    conf t
! SNMP read-only community
snmp-server community {{ olt.snmp_community }} ro
! SNMP read-write community
snmp-server community {{ olt.snmp_write_community }} rw{% if olt.snmp_port != 161 %}

! Non-default SNMP UDP port
snmp-server udp-port {{ olt.snmp_port }}{% endif %}

snmp-server enable traps
! Optional: MIB compatibility for v2c
mib-compatibility iftable v2
end
write

    {% else %} {# ═══════════════════════ HUAWEI ═══════════════════════ #}
    1
    Connect to the OLT via Telnet
    From a PC on the same network as the OLT
    Terminal
    telnet {{ olt.ip_address }}
    Log in with your current OLT admin credentials (e.g. root / admin123) — you will create the dedicated SmartOLT user in Step 3.
    2
    Enable Telnet & SNMP Services
    Open management services and disable firewall restrictions
    Huawei CLI
    # Enable Telnet and SNMP services
config
sysman service telnet enable
sysman service snmp enable
# Disable firewall blocking
sysman firewall telnet disable
sysman firewall snmp disable
# Allow connections from any interface
sysman server source telnet any-interface
sysman server source snmp any-interface
    3
    Create Dedicated SmartOLT User
    Separate account used only by SmartOLT — never share with human operators
    Huawei CLI
    # Set the SmartOLT username and password interactively
terminal user name
# (type: autoolt  then press Enter)
terminal user password
# (type: autoolt123  then press Enter)
    On some Huawei models you can also use aaa / local-user autoolt password cipher autoolt123 — check your firmware version.
    4
    Configure SNMP Communities
    Read and write community strings for monitoring and polling
    Huawei CLI
    system-view
# Enable SNMP agent
snmp-agent
snmp-agent sys-info version v2c
# Read-only community
snmp-agent community read {{ olt.snmp_community }}
# Read-write community
snmp-agent community write {{ olt.snmp_write_community }}{% if olt.snmp_port != 161 %}

# Non-default SNMP UDP port
snmp-agent udp-port {{ olt.snmp_port }}{% endif %}

quit
save

    6
    Verify PON Ports, ONUs & Unregistered ONUs via SNMP
    Run from any Linux/Windows machine that can reach the OLT — confirms SNMP is working

    System & PON Port Verification

    SNMP — System info (MIB-II, works on both vendors)
    # Check OLT is reachable and get firmware/hostname
snmpget -v2c -c {{ olt.snmp_community }} {{ olt.ip_address }} \
  1.3.6.1.2.1.1.1.0  # sysDescr  — firmware string
  1.3.6.1.2.1.1.3.0  # sysUpTime — uptime
  1.3.6.1.2.1.1.5.0  # sysName   — hostname

# Walk the full interface table (shows all PON ports)
snmpwalk -v2c -c {{ olt.snmp_community }} {{ olt.ip_address }} 1.3.6.1.2.1.2.2.1.2

    Registered ONU List & Status

    {% if olt.vendor == 'ZTE' %}
    ZTE — ONU state & serial walk
    # ONU operational state  (1=online  2=offline)
snmpwalk -v2c -c {{ olt.snmp_community }} {{ olt.ip_address }} \
  1.3.6.1.4.1.3902.1015.1010.1.1.1.5

# ONU serial numbers
snmpwalk -v2c -c {{ olt.snmp_community }} {{ olt.ip_address }} \
  1.3.6.1.4.1.3902.1015.1010.1.1.1.6

# ONU type / model
snmpwalk -v2c -c {{ olt.snmp_community }} {{ olt.ip_address }} \
  1.3.6.1.4.1.3902.1015.1010.1.1.1.3

# ONU RX power  (divide result by 100 to get dBm)
snmpwalk -v2c -c {{ olt.snmp_community }} {{ olt.ip_address }} \
  1.3.6.1.4.1.3902.1015.1010.2.1.1.4

    Unregistered ONUs (Telnet CLI)

show gpon onu uncfg gpon-olt_1/1

! Check ONU state on a specific port
show gpon onu state gpon-olt_1/1
